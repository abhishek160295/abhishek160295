Setup and schedule, once

Python 3.11+, Node for Claude Code, LibreOffice for the Excel checks, Noto Color Emoji for the kids pictures. Jobs run at 05:50, 11:50 and 16:50 IST, converted to your computer's clock.

Mac
cd carousel-engine
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m playwright install chromium
brew install --cask font-noto-color-emoji libreoffice
npm install -g @anthropic-ai/claude-code && claude
python tools/install_schedule.py --install
Windows (PowerShell)
cd carousel-engine
py -m venv .venv; .venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium
winget install TheDocumentFoundation.LibreOffice
npm install -g @anthropic-ai/claude-code; claude
python tools/install_schedule.py --install

Nothing reaches you unless it passes

The build blocks any post that fails one of these.

Code is run, not typed

SQL runs in sqlite, pandas and Python lines run, Excel formulas are computed in LibreOffice. The green answer on a slide must equal the computed value.

Your rules

Light styles, no retired formats, nothing repeated from 60 days or a rejected post, unique keyword, exact CTA with the real PDF page count.

Your voice

No hype words, no em-dashes, no emojis outside kids pictures, no price, no invented numbers.

Pixel-clean

No overflowing or clipped text, no emoji on two lines, no tiny text, PDF pages match.

Quality bar

Answers on every formula row, sample data shown, comparisons end with "Pick it if you…", hooks name a real pain.

Planner

Kids daily at 19:00 with no repeat in 60 days, roadmap max 2 a week, role pairs never repeated in 60 days, rule breaks swap to the closest proven winner.
