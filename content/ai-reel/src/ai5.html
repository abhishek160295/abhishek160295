03 / 05

Prompt like a pro

Use these 5 parts for almost any task. The last one catches most mistakes.

ROLE  You are a senior data analyst.
CONTEXT  Table sales: order_id, order_date, region, amount.
TASK  Month-on-month revenue growth % by region.
FORMAT  PostgreSQL, one line per step.
CHECK  List 2 ways this could be wrong.

How AI actually works

The 5 terms that come up in interviews and at work.

Token
The unit of text a model reads and writes. Usage is counted in tokens. (Split below is illustrative.)

Context window
How much text the model can consider at once: prompt + reply.
Temperature
Randomness. Low: consistent. High: varied.
Hallucination
A confident answer that is wrong. This is why checking output is a core skill.
