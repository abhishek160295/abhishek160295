# Inspired Daily — reel studio

Minimal stick-figure motivation reels, 1080x1920, 32s, original soundtrack.

- `engine.js` — canvas motion engine (figure rig, type, glow, camera, transitions, watermark)
- `reels/dayNNN.js` — one reel = 5 scenes x 6.4s (4 bars at 150 BPM)
- `audio.py` — original phonk-style track + SFX synced to scene cues
- `build.sh dayNNN` — renders `out/dayNNN.mp4`
- `ledger.json` — every concept used so far. Never repeat one.
