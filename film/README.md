# DISCIPLINE: an animated short, built entirely in code

A 3:24 bean-character short at 1080p and 24 fps. Every frame, line, light and sound is generated by the Python in this folder. No AI image, video or audio generators are used.

| File | Role |
|---|---|
| `script.md` | Premise, villain, counter, and the full timed script |
| `engine.py` | Vector frame and camera, boiling chalk lines, glow buffer, bloom, grain, vignette, letterbox |
| `chars.py` | Bean characters (2-bone IK, acting faces) and the shadow villain with its blurred red halo |
| `props.py` | Line-art props and light rigs |
| `scenes.py` | All 21 scenes, timed relative to each scene's start, plus HUD and captions |
| `audio.py` | Synthesized score and foley, plus the espeak-ng villain voice |
| `render.py`, `run.sh` | Resumable 15-second chunk renderer (`setsid nohup bash run.sh &`) |
| `finish.sh` | Concat, loudnorm to -14 LUFS / -1 dBTP, mux, then the delivery encode |
| `sheet.py`, `subs.py`, `thumb.py` | Contact sheets, `.srt` subtitles, and the thumbnail |

Deliverables are written to `out/`.
